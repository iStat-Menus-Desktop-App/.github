## Overview
iStat Menus for macOS turns your Mac's menu bar into a live dashboard, surfacing CPU load, memory pressure, disk activity, network throughput, battery health, and hardware sensor data without opening a separate app. Anyone who wants iStat Menus on their Mac — from developers watching CPU spikes to anyone curious about what's eating their battery — gets a persistent, glanceable read on system health. Instead of digging through Activity Monitor, iStat Menus keeps the numbers that matter one glance away, all day.

## Features
- Real-time CPU, GPU, and memory usage graphs in the menu bar
- Disk activity, capacity, and drive health monitoring
- Network upload/download speed and data usage tracking
- Battery health, cycle count, and time-remaining estimates
- Temperature and fan-speed sensor readouts

## Getting Started
After launching iStat Menus, its menu bar icons appear immediately with live readouts. Open the preferences pane to choose which modules — CPU, Memory, Disk, Network, Battery, Sensors, Time — show up in the menu bar and in what order. Click any module's menu bar item to drop down a detailed panel with graphs and history. From there you can fine-tune update intervals, colors, and which stats are shown at a glance versus in the dropdown.

## FAQ
**Is iStat Menus available for Mac?**
Yes — iStat Menus is built specifically for macOS and runs as a native menu bar app.

**How do I download iStat Menus?**
Use the download button on this page to get the installer, then move the app into your Applications folder.

**Does iStat Menus slow down my Mac?**
No — it's designed to be lightweight, sampling system data efficiently so it doesn't noticeably add to CPU or memory load.
